# `docs` Folder — OAI Tutorials

The `docs` folder contains a collection of tutorials focused on running different 5G network scenarios based on the OpenAirInterface (OAI) framework.  
These guides cover the installation, configuration, and execution of complete setups involving the Core Network, gNB, and UE, using both commercial equipment and fully emulated environments.

The goal of this collection is to provide well-structured and accessible technical documentation to support the replication and understanding of practical experiments with OAI.
